# Privacy

LocalDeck works locally and requires no account, activation, or cloud connection. Telemetry is disabled and is not implemented in version 1.0.0. Runtime installation uses only the files included with the official LocalDeck download.

Project code, databases, captured email, certificates, and diagnostics remain on the computer. A workspace export can contain project data and must therefore be treated as confidential. Passwords and private keys are not exported. Support bundles are separate and intentionally sanitized.
