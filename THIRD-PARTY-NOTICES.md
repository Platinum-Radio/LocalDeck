# Componenten en licenties

LocalDeck bundelt componenten van derden in het offline runtimepakket. Controleer vóór iedere publieke release de exacte versies, SHA-256-waarden en originele licentieteksten.

| Component | Gebruik | Licentie/project |
|---|---|---|
| Apache HTTP Server | Webserver | Apache License 2.0 |
| PHP | PHP-runtime | PHP License |
| MySQL Community Server | Database | GPLv2 met aanvullende voorwaarden |
| phpMyAdmin | Databasebeheer | GPLv2 |
| Composer | PHP-pakketbeheer | MIT |
| Mailpit | Lokale mailserver | MIT |
| Redis voor Windows | Cache en queues | Controleer meegeleverde release-licentie |
| WinSW | Windows-servicewrapper | MIT |
| mkcert | Lokale ontwikkelcertificaten | BSD 3-Clause |
| Microsoft Visual C++ Redistributable | Windows-runtimebibliotheken | Microsoft-licentievoorwaarden |
| Electron, React en Vite | Desktopinterface | Zie de meegeleverde npm-licenties |

De originele licentie- en noticebestanden in de Apache-, PHP-, MySQL-, phpMyAdmin- en Redis-pakketten blijven in de geïnstalleerde componentmappen aanwezig. LocalDeck is niet verbonden aan of goedgekeurd door de beheerders van deze projecten.
